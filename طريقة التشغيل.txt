تطبيق حسابات الموردين
=====================

أولاً: التشغيل المحلي (localhost) — للتجربة والتطوير
------------------------------------------------------
محتاج Node.js على الجهاز (nodejs.org — نسخة LTS).
  الأسهل: دبل كليك على "تشغيل التطبيق.bat" (بيعمل الخطوات دي لوحده ويفتح المتصفح)
  أو يدوي:
  1) افتح Terminal / CMD جوه فولدر local-server
  2) npm install        (مرة واحدة بس)
  3) npm start
  4) افتح  http://localhost:3000  — والتطبيق بيتوصل لوحده بقاعدة بيانات محلية
     (نفس setup.sql ونفس الصلاحيات). البيانات والصور بتتحفظ في local-server/data
  - من أي موبايل أو جهاز على نفس الواي فاي:
      • مرة واحدة: دبل كليك على "السماح من الشبكة.bat" ووافق على رسالة الصلاحيات (بيفتح البورت 3000 للشبكة المحلية بس)
      • العنوان بيظهر في الشاشة السودا وفي التطبيق ← الإعدادات، زي  http://192.168.1.5:3000
      • الكمبيوتر لازم يفضل شغال والشاشة السودا مفتوحة
  - عايز تبدأ من الصفر؟ اقفل السيرفر وامسح فولدر local-server/data

ثانياً: التشغيل الحقيقي (أونلاين)
---------------------------------
1) Supabase: اعمل مشروع جديد (Frankfurt) ← SQL Editor ← الزق setup.sql ← Run
   (اختياري) Authentication ← Providers ← Email ← اقفل Confirm email
   Project Settings ← API Keys: انسخ Project URL و Publishable key
2) GitHub Pages: الريبو ← Settings ← Pages ← Branch: main / root ← Save
3) افتح رابط الصفحة من موبايلك ← الزق الـ URL والـ key ← اعمل حسابك (أول حساب = صاحب التطبيق)
4) الإعدادات ← أضف إيميل أخوك ← "مشاركة رابط التطبيق" وابعتهوله

التثبيت على الموبايل
   - آيفون: Safari ← مشاركة ← Add to Home Screen
   - أندرويد: Chrome ← ⋮ ← Install app

ملاحظات
   - الشيك بيتحسب دفعة من يوم ما تكتبه. لو ارتد علّمه "ارتد" ومبلغه يرجع على حساب المورد.
   - أي حد مش مضاف في الإعدادات مش هيشوف أي بيانات حتى لو عمل حساب.
