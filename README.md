# حسابات المحل — ورد · زهرة

تطبيق موبايل (PWA) بالعربي: الموردين والفواتير والدفعات والشيكات، الموظفين، القروض، الخزينة (المبيع اليومي)، التقارير وكشوف الحساب.

- **الواجهة:** HTML + JavaScript من غير إطار عمل ومن غير خطوة بناء — أي استضافة ملفات ثابتة تشغّله.
- **البيانات:** Supabase (PostgreSQL + Auth + Storage) بصلاحيات RLS — الإعداد كله في `setup.sql`.
- **من غير نت:** كل البيانات متخزنة على الموبايل (IndexedDB)، وأي عملية بتتحفظ في طابور وبتتبعت لما النت يرجع — كل عملية ليها رقم مميز (`op_id`) فمبتتكررش لو اتبعتت مرتين، والتعديل على سجل اتغير من حد تاني بيتعرض كتعارض تختار فيه.

## الملفات المهمة
| الملف | إيه هو |
|---|---|
| `config.js` | رابط Supabase والـ Publishable key (مسموح يبقوا ظاهرين) + `movedTo` لنقل الرابط |
| `setup.sql` | قاعدة البيانات كاملة (الجداول، الصلاحيات، الدوال) — بيتشغل على مشروع فاضي |
| `sw.js` | ملفات التطبيق للشغل من غير نت — **زوّد رقم `CACHE` مع كل تحديث** |
| `tools/check.mjs` | اختبار قبل النشر (الكود، الملفات، الشغل من غير نت، مفيش أسرار) |
| `tools/build-dist.mjs` | بيطلع فولدر `dist` للرفع على أي استضافة |
| `.github/workflows/deploy.yml` | اختبار ← نشر على Cloudflare Pages |
| `local-server/` | سيرفر محلي بيقلّد Supabase (للتطوير وللطوارئ) |
| `docs/النشر على Cloudflare.md` | الإعداد والنشر والتحديثات |
| `docs/الطوارئ والنقل والاستعادة.md` | لو أي خدمة وقفت: النقل والاستعادة |

النسخ الاحتياطي اليومي في مستودع خاص منفصل (`mawredin-backups`) — ليه README خاص بيه.
